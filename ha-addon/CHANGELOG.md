# Changelog

## [1.0.0] - 2025-07-26

- Initial add-on release
- Multiple MySensors gateways (ethernet / RS485)
- Home Assistant MQTT discovery
- TCP traffic mirroring (ports 5003-5006)
- Node ID assignment support
- Configurable ACK and optimistic behavior (per entity)
- Multi-architecture builds (amd64, aarch64, armv7, armhf, i386)
